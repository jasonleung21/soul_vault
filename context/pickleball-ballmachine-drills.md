# Pickleball — Ball Machine Drills（Titan Drills Pro @ JEM）

> **單位說明**：Speed 用 mph（通用單位，可信）。Height／Horizontal／Spin 用 0–10 相對值（0=機台滑桿最小、10=最大）——因為 Titan 官方文件沒公開這三項的實際刻度單位（degree／RPM），不確定的數字不如老實標相對值。**下次在機台前，記下 Height／Horizontal／Spin 三個滑桿的實際 min/max，回報後這裡全部換算成真實刻度。**
> 開跑任何 set 前，先用 app 的 Test 單球功能對過落點——Titan 自己文件承認 simulator 只是近似，實際落點會因電量／球的軟硬度飄動。

## 1. Backhand Drop
| Speed | Height(0–10) | Horizontal | Spin(0–10) | Feed |
|---|---|---|---|---|
| 25–30mph | 4–5（夠弧度深球不打平） | 偏 BH 深角，離中心線~4/10 | 3，light topspin | 4–5 sec |

結構：6min 標準 push drop → 6min topspin drop/drip（餵球不變，換自己打法）
驗收：≥70% 進 kitchen 才升級；Cue：肩帶引導減少 chop；"Split after"

## 2. BH Twoey → FH Counter Combo（kitchen line, fast hands）
| | Ball1（BH） | Ball2（FH） |
|---|---|---|
| Speed | 20–25mph | 20–25mph |
| Height(0–10) | 2（平、驅動型） | 2（平、驅動型） |
| Horizontal | 離中心~3/10，BH側 | 離中心~3–4/10，反方向 FH側 |
| Spin(0–10) | 2，flat/light topspin | 2，flat/light topspin |
| Feed | 1.0–1.5 sec → ball2 | 4–5 sec → 下個 combo |

結構：3 sets × 8–10 combo reps，組間休 90 sec
驗收：twoey 控制回擊 ≥80%；FH counter 有效落點 ≥60%
Cue：ball1 到之前預備動作要一致，不能提早洩漏方向

## 3. BH Flick vs Roll（隨機高度，live read）
| | High → Flick | Low/Mid → Roll |
|---|---|---|
| Speed | 10–12mph | 10–12mph |
| Height(0–10) | 6–7（胸–頭高觸球） | 2–3（低，近網帶） |
| Horizontal | 離中心~2/10，BH pocket | 離中心~2/10，BH pocket |
| Spin(0–10) | 1，flat/minimal | 5–6，light–medium topspin |
| Feed | 2.5–3.5 sec | 2.5–3.5 sec |

結構：不規則交錯序列（先查 app height 欄是否有 random/shuffle 開關，有就直接用）；2–3 sets × 15–20 balls
驗收：判斷正確率 ≥80%；選對後執行進場率 ≥70%
Cue：flick＝「Hip, snap over」；roll＝更長刷球路徑，近似 FH topspin drop 的 hinge 手感

## 4. Forehand Side Dinking（拒絕縮回中路）
| | Scoop trigger | Roll trigger | 偽裝/speed-up（Block B，每4球1顆） |
|---|---|---|---|
| Speed | 8–10mph | 8–10mph | 12–15mph |
| Height(0–10) | 2（低，近網帶） | 2（低，近網帶） | 3–4（稍微彈高） |
| Horizontal | 離中心~7–8/10，FH邊線 | 離中心~7–8/10，FH邊線 | 離中心~7–8/10，FH邊線 |
| Spin(0–10) | 1，flat/light backspin | 5–6，light–medium topspin | 3，混合 |
| Feed | 2.5–3 sec | 2.5–3 sec | 2.5–3 sec，不規則穿插 |

結構：8min 純寬球 dink（每球強迫換握把）→ 4–7min 偽裝層
驗收：**每組「縮回中路放掉」次數 = 0**（真正 KPI）；乾淨進場 ≥70%；Block B dink/攻擊判斷正確率 ≥70%
Cue：球到之前先承諾移動；不管最後 dink 或 speed-up，backswing 要長一樣

## 建議跑法
**順序：Drill 4 → Drill 2 → Drill 3 → Drill 1**（約 50–58 min + 轉換時間）
理由：Drill 4 唯一有真正側向第一步負荷，腿最新鮮時做；Drill 2/3 是反應/決策速度訓練，神經系統新鮮時效果最好；Drill 1 節奏慢、最耐疲勞，適合收尾。
